## Milestone V1.0

### Goals:


- Data-Architecture (finished Diagram)
- Backlog of Issues 
- Database modeling

### **1. Issue-Backlog:**

At the start of our project we want to create a Backlog of Issues.
Goal is to have a clear view of our assignments for VoBi-Tour.
Not every Issue will probably be used, but those we want to use will be ready for use for future milestones.

### **2. Database modeling:**

First thing we want to create is our database. What does it save?
Trashcans, adresses, size of the atuomobiles, users etc.
Offline usage will also be an issue regarding our database.
Users can add data to the database (photos, names, descriptions) wich can be seen by other users.

### **3. Data-Architecture:**

Goal is to visualize via diagram-applications what our agents/actors are doing. Who talks to whom, what is our data-traffic,
how can we improve performance, what does our application look like on the inside.
